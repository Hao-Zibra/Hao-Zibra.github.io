Physics-based battery aging simulation with PyBaMM

An open-source PyBaMM Doyle–Fuller–Newman (DFN) pipeline that injects coupled aging, SEI growth, lithium-inventory loss, active-material loss, and particle cracking, then simulates 1000-cycle capacity fade and the evolution of impedance and DRT features. It reproduces a capacity knee and a matching polarization-resistance acceleration, and shows, at the pattern level, that the DRT polarization-resistance growth is a degradation signature shared with two measured public datasets.

1 · The model and its baseline

The workhorse is the DFN electrochemical model. It resolves solid-phase diffusion and the deep-DOD behavior where fade physics lives. A baseline check confirms the model choice before any aging is layered on: the reduced-order SPMe model diverges from DFN by up to ~320 mV over the 75–99% DOD window, so the full DFN carries all the cycling here.

2 · A thousand cycles of coupled aging

Three configurations run to 1000 cycles: the full O'Kane 2022 degradation recipe, a knee-forcing config (particle cracking ×25, which I softened from the literature ×50/×30 so it produces a clear knee and still survives all 1000 cycles), and a no-degradation control. A change-point detector locates the capacity knee where fade accelerates 2.16×.

NMC PUBLIC-PARAM SIM Thousand-cycle capacity retention. Three configs vs cycle number; the dotted line marks the detected knee (cycle 677) in the cracking config. End retention: 100.0% control, 96.8% base, 94.3% knee.
NMC PUBLIC-PARAM SIM Mechanism decomposition. Loss split into lithium-inventory (LLI) and negative active-material (LAM) loss. In the knee config (dashed) the knee is accelerating LLI. LAM is disabled in this ablation, isolating the mechanism.

All gates pass: monotonicity, closure, knee detection, and control drift (control stays flat at exactly 100.0%). Per-segment subprocess isolation keeps peak memory in budget.

3 · The impedance analogue: EIS → canonical DRT

At every ~100 cycles the aged cell is probed with a linearized EIS sweep (10 kHz–1 mHz) and deconvolved with the canonical distribution-of-relaxation-times engine. The knee that shows up in capacity has an impedance twin: the polarization resistance R_pol accelerates in exactly the config that knees. This cell's aging impedance is an ohmic shift plus polarization/diffusion growth, not a charge-transfer semicircle, so R_pol (total polarization) is the tracked interfacial quantity.

NMC PUBLIC-PARAM SIM Polarization-resistance evolution. R_pol vs cycle. The knee config accelerates (7.6 → 17.1 mΩ, 2.25×) while the base config stays gentle and the control is flat: the impedance analogue of the capacity knee.

4 · Pattern-level comparison with public measured data

I run the same DRT engine on the simulated cell and on two measured public datasets, so the R_pol-growth signature is computed identically on both sides. The question is deliberately modest: does the type of degradation signature transfer across chemistries? The answer is a qualified yes: read strictly at the pattern level.

5 · Calibration: parameter estimation as model calibration

NMC-FREE · ALL-PUBLIC LANE A separate, deliberately broken case: the PyBaMM DFN with the public Prada2013 A123-LFP parameter set (26650), area-scaled so current density is preserved, against a real measured curve: Severson 2019 cell b1c0, cycle 2, 4C discharge (A123 18650, same manufacturer and chemistry family; public dataset). Out of the box the model is badly wrong at rate: it delivers 0.52 of 1.05 Ah at 4C with a full-range voltage residual of RMSE 729 mV: the parameter set's genuine rate limitation, not a scaling artifact.

PUBLIC-PARAM SIM + PUBLIC DATA Measured vs baseline vs calibrated. The bounded one-parameter recalibration moves the model from 0.52 to 1.01 Ah delivered and RMSE 729 → 154 mV (green): the top-ranked capacity parameter saturates its ≈0.70 packing bound and cannot fix the cliff alone, so the next-ranked lever, the anode particle radius, scanned in-bounds to ×0.25, takes over. That escalation, parameter hits its physical bound → move to the next-ranked lever, is the constrained-calibration loop in action.
Residual diagnosis. Three orthogonal residual channels: a capacity-cliff signature points at transport/kinetics parameters that starve the cell at rate; a vertical-offset signature points at ohmic/exchange-current terms; shape signatures bend the mid-curve. The attribution is the measured Δ per channel, not intuition.
Sensitivity ranking. I perturbed ten physical parameters ±10% and scored them per channel. Top three by |ΔRMSE|: anode active-material fraction (69 mV, capacity cliff), anode particle radius (55 mV, capacity cliff), anode solid diffusivity (25 mV, capacity cliff). The diagnosis and the winning lever agree: anode diffusion time τ = r²/D ≈ 2.3 h far exceeds the 900-s 4C discharge, so the anode surface starves.
The TCAD line. This loop, measured characteristic vs physics simulation → residual-shape diagnosis → numerically-ranked parameter sensitivity → targeted recalibration, is workflow-isomorphic to semiconductor TCAD model calibration (I–V/C–V residuals → process & transport parameter attribution → re-fit).
SCOPE Public parameter set vs public dataset; the 26650 set is area-scaled to an 18650 capacity (current density preserved) — a pedagogical calibration demo, not a validated A123-18650 cell model, and unrelated to any solid-state system. Baseline mismatch is the parameter set's genuine 4C behavior, not an artifact of the scaling.

Conclusion: why it matters

Why it matters. A physics model that reproduces a capacity knee and its impedance twin from first principles is a controlled bench for degradation diagnostics: you can impose a mechanism and test whether a signature, here, DRT polarization-resistance growth, actually tracks it before trusting that signature on real cells. That makes it a bridge between the data-driven pages on this site and the mechanisms underneath them. This is a public-parameter methods demonstration on a liquid-NMC model. Every cross-dataset link stays pattern-level, and nothing here represents or is validated against a solid-state cell.

6 · Honest limitations

  • Liquid NMC model, not a solid-state cell; all cross-dataset correspondence is pattern-level.
  • The knee accelerant (cracking multiplier) is a literature device to force a knee within feasible compute; its magnitude was chosen for survival to 1000 cycles, not fit to data.
  • The model has no distinct charge-transfer arc; a closer analogue to a measured interfacial resistance would need an explicit film/contact-resistance addition (future work).
  • The simulated knee cell ends at ~94% SOH (never reaches 80% end-of-life), so its knee-location fraction is relative to the run window, not a true cycle-life.
Scope. This page displays figures and plain conclusions from a public-input methods pipeline. The pipeline source is not released here, it imports a private shared DRT/figure engine, so a public code release would go through a separately sanitized package, not this repository. What this page demonstrates is physics-based-modeling discipline: pick the right-fidelity model, inject coupled degradation, validate the numerics, and compare to measured data only as far as the chemistry honestly allows.
